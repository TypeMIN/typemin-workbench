# 외부 음원과 음성 사용 기록

야구 게임의 소리는 기본적으로 브라우저 Web Audio로 합성한다(`components/baseball-game/audio/soundscape-engine.ts`). 외부 음원을 추가할 때는 아래 표에 출처, 라이선스, 가공 내용을 남긴다.

| 용도    | 출처                                  | 라이선스               | 파일 | 가공                  |
| ------- | ------------------------------------- | ---------------------- | ---- | --------------------- |
| 심판 콜 | 사용 기기의 음성 합성(Web Speech API) | 기기 제공, 파일 미포함 | 없음 | 콜별 속도·높낮이 조정 |

## 허용 기준

- CC0 또는 저작자 표시만 요구하는 라이선스(CC-BY)만 쓴다. CC-BY는 크레딧 페이지에 출처를 표기한다.
- 비상업 전용(NC), 변경 금지(ND), 라이선스가 불분명한 자료는 쓰지 않는다.
- TTS로 파일을 미리 생성할 때는 모델 가중치의 라이선스까지 확인한다(예: MeloTTS는 MIT로 표기되어 있으나 도입 시 원문을 다시 확인).

## 후속 옵션

- 기기마다 음색이 다른 문제를 없애려면, 라이선스가 확인된 오픈소스 TTS로 14개 콜을 한 번 생성해 `public/sounds/umpire/`에 두고 `UmpireVoice`보다 먼저 재생한다.
