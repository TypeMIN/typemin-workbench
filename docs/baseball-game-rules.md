# 야구 게임 `core-v1` 규칙 결정 기록

이 문서는 `/baseball-game`의 카드 없는 코어 엔진에서 공개 규칙의 모호한
부분을 어떻게 해석했는지 기록한다. 기준 자료는 WING Board Game의
[Base on Board 규칙 정리](https://www.wingboardgame.com/2026/06/blog-post.html)다.

## 기본 원칙

- 공개된 3개 D12의 면 구성과 주자 이동표를 우선한다.
- 공개 규칙과 실제 야구가 충돌하거나 공개 규칙이 생략된 경우 실제 야구의
  강제진루, 세 번째 아웃, 끝내기 원칙을 적용한다.
- 세 번째 아웃이 타자주자 또는 강제주자의 아웃이면 같은 플레이의 득점은
  인정하지 않는다.
- 정규 이닝 종료 후 동점이면 승부치기 주자 없이 연장전을 진행한다.

## 타구 해석

- `GF`: 1루에 주자가 있으면 가장 앞선 강제주자를 아웃시키고 뒤의 강제주자와
  타자주자가 한 베이스씩 이동한다. 1루가 비어 강제 상황이 아니면 기존 주자는
  멈추고 타자만 아웃된다.
- `G3`: 기존 3루 주자의 득점 시도 후, 남은 주자 상황에 `GF`를 적용한다.
- `GA`: 타자는 아웃되고 기존 주자는 한 베이스씩 진루한다.
- `F2`: 2루 주자는 3루로, 3루 주자는 홈으로 태그업한다.
- `F3`: 3루 주자만 홈으로 태그업한다.
- `FA`: 모든 기존 주자가 한 베이스씩 태그업한다.
- `D3`: 공개 표의 표현이 서로 달라 용어표를 우선했다. 타자는 2루에 남고 기존
  주자는 모두 득점하는 2루타다.

## 경기 종료

- 마지막 정규 이닝 초가 끝났을 때 홈팀이 앞서면 말 공격을 생략한다.
- 마지막 정규 이닝 또는 연장전 말에 홈팀이 앞서는 순간 끝내기로 종료한다.
- 정규 이닝 말이 동점으로 끝나면 다음 이닝 초로 넘어간다.
