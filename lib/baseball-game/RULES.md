# 야구 게임 `pro-cards-v1` 규칙 결정 기록

기준 자료는 WING Board Game의 공개 `Base on Board 규칙 정리`다.

- https://www.wingboardgame.com/2026/06/blog-post.html
- 주사위 이동표와 공격·수비 각 40장의 수량 및 사용 조건을 따른다.
- 원본 카드 이미지와 설명 문구는 사용하지 않고, 화면 문구는 이 프로젝트용으로 다시 작성한다.

## 디지털 진행을 위한 결정

1. 실제 야구의 인필드플라이는 심판의 자동 선언이므로, 0·1아웃 1·2루 또는 만루의 `PO`에서 자동 적용한다. 이 상황에서는 `IFD`를 사용할 수 없다.
2. `LDP`와 `RHB`처럼 수비가 여러 주자 중 하나를 고르는 카드는 흐름을 멈추지 않도록 가장 앞선 주자를 자동 대상으로 삼는다.
3. `HNR`과 `RNH`의 뜬공 병살도 가장 앞선 주자와 타자를 아웃 처리한다.
4. `RNH`에서 1·2루 주자가 함께 출발하면 `CS3`, `CS2` 순서로 각각 저지할 수 있다. 남은 주자는 한 베이스 진루한 뒤 원래 투구 판정을 처리한다.
5. `RNH`가 파울이면 사용 카드를 손으로 돌려주고 교체로 뽑힌 카드는 덱으로 반환한다.
6. `1H1E`와 `HNR`/`RNH`의 안타 추가 진루는 이미 홈에 들어온 주자에게 중복 적용하지 않는다.
7. 카드로 세 번째 아웃이나 끝내기 득점이 발생하면 대기 중인 주사위 판정을 즉시 취소한다.
8. 세 번째 아웃이 타자 또는 강제주자의 아웃이면 해당 플레이의 진루와 득점은 취소한다. 현재 엔진은 일관된 재현을 위해 카드가 만든 복합 플레이의 세 번째 아웃에도 같은 보수적 기준을 적용한다.

## 이번 버전에 포함된 범위

- D12 투구·타격·안타 전체 이동표
- 공격 18종 40장, 수비 20종 40장
- 스퀴즈, 보살, 병살·삼중살, 포수 견제, 파울 플라이, 타격·주루방해
- 히트 앤드 런, 런 앤드 히트 특수 결과
- 자동 인필드플라이
- 카드 보충, 공수교대 재분배, 버림 더미 재순환

## 별도 후속 범위

챌린지는 공개 자료에 20장의 `Confirm`/`Reverse` 구성 비율과 카드 공개 절차가 명시되어 있지 않다. 임의 확률을 넣어 경기 결과를 왜곡하지 않도록 이번 규칙 버전에는 포함하지 않고, 실제 구성 확인 후 독립 규칙 버전으로 추가한다.
