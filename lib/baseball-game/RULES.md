# 야구 게임 `pitch-duel-v3` 규칙 결정 기록

기준 자료는 WING Board Game의 공개 `Base on Board 규칙 정리`다.

- https://www.wingboardgame.com/2026/06/blog-post.html
- 공격·수비 각 40장의 카드 수량과 사용 조건, 타구·주루 이동표를 따른다.
- 원본 카드 이미지와 설명 문구는 사용하지 않고, 화면 문구는 이 프로젝트용으로 다시 작성한다.

## 디지털 진행을 위한 결정

1. 실제 야구의 인필드플라이는 심판의 자동 선언이므로, 0·1아웃 1·2루 또는 만루의 `PO`에서 자동 적용한다. 이 상황에서는 `IFD`를 사용할 수 없다.
2. `LDP`와 `RHB`처럼 수비가 여러 주자 중 하나를 고르는 카드는 흐름을 멈추지 않도록 가장 앞선 주자를 자동 대상으로 삼는다.
3. `HNR`과 `RNH`의 뜬공 병살도 가장 앞선 주자와 타자를 아웃 처리한다.
4. `RNH`에서 1·2루 주자가 함께 출발하면 `CS3`, `CS2` 순서로 각각 저지할 수 있다. 남은 주자는 한 베이스 진루한 뒤 원래 투구 판정을 처리한다.
5. `RNH`가 파울이면 사용 카드를 손으로 돌려주고 교체로 뽑힌 카드는 덱으로 반환한다.
6. `1H1E`와 `HNR`/`RNH`의 안타 추가 진루는 이미 홈에 들어온 주자에게 중복 적용하지 않는다.
7. 카드로 세 번째 아웃이나 끝내기 득점이 발생하면 대기 중인 투구·타구 판정을 즉시 취소한다.
8. 세 번째 아웃이 타자 또는 강제주자의 아웃이면 해당 플레이의 진루와 득점은 취소한다. 현재 엔진은 일관된 재현을 위해 카드가 만든 복합 플레이의 세 번째 아웃에도 같은 보수적 기준을 적용한다.

## 이번 버전에 포함된 범위

- 투수의 스트라이크·볼 선택과 타자의 스윙·지켜보기 2×2 심리전
- 선택 조합별 컨택·파울·헛스윙 및 땅볼·뜬공·안타·홈런 자동 판정
- 공격 18종 40장, 수비 20종 40장
- 스퀴즈, 보살, 병살·삼중살, 포수 견제, 파울 플라이, 타격·주루방해
- 히트 앤드 런, 런 앤드 히트 특수 결과
- 자동 인필드플라이
- 카드 보충, 공수교대 재분배, 버림 더미 재순환

## 별도 후속 범위

챌린지는 공개 자료에 20장의 `Confirm`/`Reverse` 구성 비율과 카드 공개 절차가 명시되어 있지 않다. 임의 확률을 넣어 경기 결과를 왜곡하지 않도록 이번 규칙 버전에는 포함하지 않고, 실제 구성 확인 후 독립 규칙 버전으로 추가한다.

## 심리전 확률 결정

- 투수는 스트라이크와 볼 중 하나를 비공개로 선택한다. 타자에게는 예상 위치나 스트라이크·볼 힌트를 제공하지 않는다.
- 타자는 스윙과 지켜보기 중 하나만 선택한다. 스트라이크+스윙 또는 볼+지켜보기면 타자가, 스트라이크+지켜보기 또는 볼+스윙이면 투수가 심리전에서 이긴다.
- 스트라이크에 스윙하면 컨택 82%·파울 12%·헛스윙 6%를 적용한다. 볼에 스윙하면 컨택 6%·파울 14%·헛스윙 80%를 적용한다.
- 타자가 이긴 스윙이 컨택되면 땅볼과 뜬공에서 각각 12%p를 옮겨 안타 17%p·홈런 7%p를 더한다. 전체 안타성 결과가 24%p 증가한다.
- 투수가 이긴 유인구가 컨택되면 안타 15%p·홈런 3%p를 땅볼과 뜬공으로 옮긴다. 전체 안타성 결과가 18%p 감소한다.
- 컨택 뒤 타구와 안타 진루는 같은 상태 RNG로 즉시 판정한다. 클라이언트는 중간 결과를 선택하거나 생성하지 않는다.
- 상세 확률은 `duel.ts`에 고정한다. UI에는 선택마다 핵심 보상 하나만 표시해 한 번의 판단에 집중시킨다.
- 투수 선택과 실제 위치는 판정 전 수비팀과 서버에만 존재한다. 공격팀과 공용 화면에는 잠금 상태만 제공하고, 판정 후 두 선택과 실제 위치를 공개한다.
- 체력·구종·실투와 투수 교체는 이 규칙 버전에 포함하지 않되, 판정기를 교체할 수 있도록 심리전 모듈을 코어 엔진과 분리한다.

## `catcher-view-v1` 기록·연출 결정

- `H`는 자동 안타 진루 결과, 홈런, `HRC`, `1H1E`에 기록한다. `1H1E`는 안타와 수비 실책을 각각 하나씩 기록한다.
- `E`와 `POE`만 수비팀 실책으로 기록하며 방해·주루방해는 실책에 포함하지 않는다.
- `B`는 볼넷과 몸에 맞는 공만 포함하며 보크와 폭투는 제외한다.
- 세 번째 아웃으로 취소된 득점은 해당 이닝 점수에도 반영하지 않는다. 마지막 회말 생략은 `X`, 미진행 이닝은 `-`로 표시한다.
- 실제 투구 위치는 상태 RNG로 한 번만 생성해 이벤트에 기록하며, 모든 기기와 리플레이에서 동일한 값을 사용한다. 예상 위치는 생성하지 않는다.
- 투구 선택부터 판정까지 포수 시점의 큰 스트라이크존을 사용하고, 인플레이 타구가 발생하면 탑뷰 경기장으로 전환한다.
- 효과음은 브라우저 Web Audio로 합성하며 녹음 음성이나 외부 저작물은 사용하지 않는다.
